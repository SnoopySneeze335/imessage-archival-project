# imessage-ap

A self-hosted, open-source archive for iMessage history. It imports local
iPhone backups, keeps every message and attachment permanently, and shows
them in a fast, iMessage-like web app. It runs as one Docker container for a
single user, and no data leaves your server.

**Status:** early development (Milestone 1, Foundation). Not usable yet.
